01 · accepted brief

one narrow job, done carefully.

Outcome

A visitor states what care, environment, specialist support, and lifetime commitment are real. urpet returns zero to three profiles worth researching and a short provider checklist. If a non-negotiable need is missing, the result says “prepare first.”

Audience

First-time and uncertain prospective owners who need more than a personality quiz, especially people drawn to an animal by appearance, media, or a vague idea of ease.

Delivered value

A complete deterministic brief before any support request: matching reasons, difficult requirements, primary welfare sources, and three questions for a shelter, rescue, breeder, veterinarian, or experienced keeper.

Not promised

No perfect-pet verdict, behavior prediction, veterinary diagnosis, provider endorsement, automatic donation-to-AI transfer, permanent guide availability, or claim that abuse can be made impossible.

Core rule: a preference score may order compatible profiles. It may never outweigh a hard care, household-health, habitat, veterinary, or whole-life conflict.

04 · selected experience

nine answers to a bounded brief.

1. Frame
open, known kind, or compare
2. Boundaries
time, space, interaction, food
3. Gates
household, vet, lifetime
4. Result
0–3 leads + prepare-first
5. Act
sources, provider questions, print

Conversation behavior

  • One fieldset visible at a time.
  • Visible “question n of 9” progress.
  • Back never erases later answers.
  • Invalid lane counts explain the exact correction.
  • Focus moves to each legend and the result title.

Result anatomy

  • Plain “research leads, not a verdict” heading.
  • One ordered list, never a wall of result cards.
  • Exact local profile photo only after matching, with creator and license.
  • Fit and check-first notes visible; full research notes disclosed on demand.
  • Hard conflicts in a separate prepare-first block.

Fallbacks

  • No reviewed fit may be the correct result.
  • No JavaScript still shows method, sources, dog module, and email.
  • Guide failures never alter the deterministic brief.
  • Unsupported animals stay researching.

05 · support without accounts

one shared pool, never personal access.

Visitor promise

  • The matcher is free, anonymous, and unlimited.
  • Buy Me a Coffee appears only after a complete result.
  • A note containing urpet or legacy urdog assigns 75% to a Cerebras-credit earmark and 25% to fees/upkeep.
  • Support benefits the shared optional guide; it does not buy the supporter priority or extra personal use.

Provider truth

Buy Me a Coffee supplies signed event notifications; it does not automatically buy Cerebras credit. Cerebras credit is added in its Cloud Console. Therefore shared use opens only after both a qualifying support earmark and a separately verified provider-funding receipt exist.

Owner-funded receipts are separately capped at $10 total.

Usage authorization

available = verified owner credit
          + min(active 75% support earmarks, verified support credit)
          - reserved model calls
          - settled model cost

The optional guide is one request, not a conversation: select a compatible profile, pass Turnstile, and receive exactly three repository-reviewed provider questions. The model may choose only three allowlisted question IDs; it cannot send prose to the page. The guide is hidden when configuration, daily allowance, or prepaid budget is unavailable.

06 · implementation contract

deterministic core; gated optional organizer.

Browser

Static HTML/CSS/JavaScript. Closed answer vocabulary. Deterministic ranking. No account, cookie profile, user upload, or free-form prompt. The Turnstile script loads only after the status endpoint reports a funded guide ready.

Cloudflare Worker

Canonical redirects and security headers; BMC webhook; non-sensitive guide status; exact production-host guide endpoint; Cloudflare rate limiter; Turnstile Siteverify; provider timeout; and strict question-ID validation.

D1

Privacy-minimized support events, append-only provider-funding receipts, exact UTC-day limits, durable per-request reservations, one aggregate budget, and per-call profile/token/cost/outcome audit. No identity, IP, raw note, prompt, or output.

Abuse and accounting controls

  1. Verify the exact raw BMC body with HMAC-SHA256 and constant-time comparison before parsing.
  2. Accept only live donation.created and donation.refunded events; make event and payment handling idempotent.
  3. Normalize only for the keyword decision; never persist the support note.
  4. Validate guide origin, content type, body size, exact keys, profile ID, and every answer ID.
  5. Use a three-per-minute per-IP edge limiter and managed Turnstile. Send the edge IP to Siteverify for verification context, but never store it.
  6. Require server-side Turnstile success, a single-use idempotency key, the exact action, and the exact urdog.dev hostname; disable Workers.dev and preview-host access.
  7. Enforce exact D1 UTC-day ceilings of 250 reservations and $0.10 committed model spend, independent of IP rotation.
  8. Create a durable reservation before Cerebras, settle it exactly once, and conservatively charge stale or unknown provider outcomes through the 15-minute reconciliation job.
  9. Accept only three unique IDs from the selected profile’s reviewed question bank, then map those IDs to repository-owned text. No model-created prose reaches the page.

07 · release proof

done means observable.

Automated

  • Exactly ten lanes and eleven specific launch profiles.
  • Hard-conflict scenarios across aquarium, bird, rabbit, hamster, tortoise, gecko, and snake profiles.
  • Dog module remains nine questions, 205 breeds, 205 licensed local photos, and `/dogs/` deep links.
  • Signed create/refund idempotency, out-of-order refund, 75%, privacy schema, append-only receipts, $10 owner cap, and dual funding ledger.
  • Closed guide input, exact host/origin/Turnstile checks, distributed daily limits, concurrent reservations, allowlisted output, token settlement, and stale/unknown-provider accounting.
  • Ten exact post-match photos, metadata, sitemap, headers, generated pages, CSS balance, 320 px rules, reduced motion, print, and deployment dry run.

Browser and production

  • Complete a normal brief and a no-lead hard-conflict brief at desktop and phone widths.
  • Keyboard focus follows the conversation; no horizontal overflow at 320 px.
  • Unfunded guide remains hidden; deterministic result remains complete.
  • Buy Me a Coffee opens through the outbound confirmation.
  • Cache-busted live checks confirm the exact commit and Worker version after deployment.
Protected release gates: adding or rotating secrets, creating a Turnstile widget, configuring the BMC webhook, applying remote D1 state, or buying Cerebras credit requires current authorization. The deterministic urpet release may deploy with the shared guide resting.

08 · primary provider evidence

claims that shape the architecture.

  • Buy Me a Coffee webhook setup and signature verification.
  • Cerebras Account & Billing: balance and credit addition live in the Cloud Console.
  • Cerebras public-model price reference: gpt-oss-120b was $0.35/M input and $0.75/M output tokens on 2026-08-12. gemma-4-31b was $0.99/M input and $1.49/M output, so it is not the cheaper text organizer. A live public-endpoint gate must match the selected model pin before the guide is enabled.
  • Cloudflare Turnstile server-side validation: tokens require Siteverify and are single-use.
  • Pet welfare links are attached directly to each shipped profile in the product source and result UI.
